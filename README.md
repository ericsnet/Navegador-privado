# Navegador privado

Explora una interfaz experimental de navegador web con pestañas, marcadores, historial, herramientas y opciones de personalización. El repositorio reúne varias etapas del proyecto, desde una interfaz básica hasta una experiencia más completa. Algunas opciones de privacidad son simulaciones y no garantizan anonimato ni protección real.

> **Aviso sobre privacidad y seguridad:** el nombre del proyecto no garantiza anonimato ni protección real. Varias funciones son simulaciones o dependen de cómo el navegador anfitrión gestione las páginas, las conexiones y el almacenamiento. No lo consideres un sustituto de un navegador con protecciones de privacidad auditadas.

## Versiones

### [Versión base](./Versi%C3%B3n%20base/)

**Objetivo:** establecer la estructura y las interacciones esenciales.

- Interfaz principal con barra lateral, pestañas y barra de dirección.
- Acciones básicas de navegación: atrás, adelante y recargar.
- Pantalla de inicio con reloj, fecha, saludo y accesos rápidos a sitios.
- Creación, selección y cierre de pestañas.
- Control de pantalla completa.
- Acción «¡PÁNICO!» con una pantalla superpuesta para cambiar rápidamente lo que se muestra.

Es la versión más sencilla del repositorio y sirve como referencia para entender la idea inicial del proyecto.

### [Versión 1](./Versi%C3%B3n%201/)

**Objetivo:** convertir la interfaz básica en un entorno con herramientas y ajustes.

- **Organización:** paneles de marcadores, historial y herramientas; menú contextual para acciones sobre las pestañas.
- **Personalización:** temas (incluidos claro, océano, bosque, atardecer, Nord y Dracula), color de acento, fondos y opciones de interfaz.
- **Productividad:** modo Focus con temporizador, widgets de notas, tareas, Pomodoro, calculadora, calendario, reloj y otros accesos.
- **Navegación:** sugerencias de URL, gestión de pestañas, zoom, pantalla completa y acceso a páginas recientes.
- **Herramientas:** traductor, código QR, conversor y utilidades de texto.
- **Opciones adicionales:** pantalla de bloqueo configurable, camuflaje de la interfaz y ajustes de seguridad.

Algunas opciones son herramientas de interfaz o demostraciones; su presencia no implica que exista una protección de seguridad efectiva.

### [Versión 2](./Versi%C3%B3n%202/)

**Objetivo:** ampliar las funciones y centralizar más controles en la propia interfaz.

- **Navegación y organización:** pestañas, historial, marcadores con carpetas, lista de lectura, búsqueda de pestañas y accesos rápidos editables.
- **Paneles y herramientas:** widgets configurables, notificaciones, consola de desarrollo, barra para buscar dentro de una página y modo de lectura.
- **Personalización:** temas, colores, tamaño de texto, posición de la barra lateral, título e icono personalizados y ajustes de apariencia.
- **Privacidad configurable:** opciones de camuflaje, bloqueo de la interfaz, modo de emergencia y configuración de servicios de proxy. Estas opciones no garantizan anonimato.
- **Productividad:** notas, tareas, Pomodoro, calendario, calculadora, reloj, dados/moneda y seguimiento del progreso.
- **Juegos:** sección de juegos integrada y opciones para configurar algunos parámetros.
- **Datos y perfiles:** sesiones, alias, importación/exportación de datos y ajustes de accesos directos.
- **Funciones experimentales:** modo Picture-in-Picture, código QR, estadísticas y paleta de comandos.

La disponibilidad y el funcionamiento real de cada herramienta dependen de la implementación y de las restricciones del navegador donde se abra el proyecto.

### [Versión 3](./Versi%C3%B3n%203/)

**Objetivo:** continuar la ampliación de la versión 2 y reorganizar los accesos para hacer más directas las herramientas de navegación.

Incluye gran parte del conjunto de funciones de la versión anterior, con cambios en la navegación y en la presentación de los controles:

- Acceso rápido a la búsqueda mediante **Ctrl+K** y una paleta de comandos.
- Barra de herramientas de navegación desplegable para agrupar acciones.
- Accesos visibles a vista dividida, modo lectura, Picture-in-Picture, captura de pantalla, código QR, compartir URL y guardar páginas para leer después.
- Paneles de marcadores e historial, widgets, juegos y notificaciones.
- Ajustes de apariencia, buscador, camuflaje, seguridad, sesiones, alias y atajos.
- Herramientas de productividad y funciones experimentales heredadas de la versión 2.

La carpeta también contiene **[Versión separada](./Versi%C3%B3n%203/Versi%C3%B3n%20separada/)**, un directorio adicional relacionado con esta etapa del proyecto.

### [Versión 4](./Versi%C3%B3n%204/)

**Objetivo:** refinar la interfaz y reunir más opciones en una versión más completa.

- **Interfaz:** diseño de cristal, animaciones, estados visuales más cuidados y controles con indicadores de foco visibles.
- **Navegación:** gestión de pestañas, sugerencias de direcciones, zoom y opciones de navegación reorganizadas.
- **Apariencia:** temas, color de acento, ajustes de interfaz y modo nocturno.
- **Herramientas de navegación:** vista dividida, modo lectura, Picture-in-Picture, captura de pantalla, código QR, compartir URL, autoactualización y panel web lateral.
- **Buscador:** selección de motor y posibilidad de configurar motores de búsqueda personalizados.
- **Organización:** marcadores, historial, lista de lectura, sesiones, alias y herramientas de productividad.
- **Funciones adicionales:** nueva pestaña de incógnito como opción de interfaz, consola JavaScript, paleta de comandos y escáner de seguridad experimental.
- **Productividad y ocio:** widgets, temporizador, convertidor, juegos y otras utilidades integradas.

El escáner de seguridad y las opciones con nombres relacionados con la privacidad deben tratarse como funciones experimentales, no como una auditoría ni una garantía de protección.

## Cómo probar una versión

1. Clona o descarga este repositorio.
2. Entra en la carpeta de la versión que quieras probar.
3. Abre el archivo `index.html` en un navegador moderno.

Por ejemplo, para clonar el proyecto:

```bash
git clone https://github.com/ericsnet/Navegador-privado.git
cd Navegador-privado
```

La apertura directa del archivo puede ser suficiente para la interfaz, pero algunas funciones pueden requerir conexión a Internet, permisos del navegador o un contexto de ejecución concreto. Si una función no responde, comprueba la consola de desarrollo.

## Tecnologías

- **HTML** para la estructura.
- **CSS** para el diseño, los temas, las animaciones y la adaptación de la interfaz.
- **JavaScript** para la navegación simulada, las pestañas, los paneles, los ajustes y las herramientas interactivas.
- **Google Fonts (Inter)** y **Material Icons Round** para tipografía e iconos; requieren acceso a sus recursos externos si no están disponibles en caché.

## Estado del proyecto

Proyecto experimental en evolución. Las versiones representan distintas etapas y pueden diferir en estabilidad, organización y funciones disponibles. No se debe asumir que todas las opciones funcionan como las de un navegador de escritorio completo.
