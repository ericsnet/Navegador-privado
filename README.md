# Navegador privado

Interfaz experimental de navegador web creada con HTML, CSS y JavaScript. El proyecto reúne varias iteraciones de diseño en carpetas independientes para poder consultar y comparar su evolución.

## Características de la versión 4

- Interfaz oscura con efectos de cristal y varios temas visuales.
- Diseño adaptable a pantallas pequeñas.
- Barra de navegación y gestión de pestañas.
- Barra lateral con accesos a herramientas y paneles.
- Interfaz en español.

> **Importante:** el nombre «Navegador privado» describe el proyecto, no una garantía de anonimato o seguridad. No debe considerarse un sustituto de un navegador con protecciones de privacidad auditadas. La privacidad real depende de cómo se cargan las páginas, del almacenamiento, de las conexiones y de las protecciones implementadas.

Cada versión contiene su propio punto de entrada `index.html`.

## Cómo probarlo

1. Descarga o clona el repositorio.
2. Abre la carpeta de la versión que quieras probar.
3. Abre su archivo `index.html` en un navegador moderno.

Algunas funciones pueden depender de servicios externos o de las restricciones del navegador. Para comprobar el comportamiento completo, revisa la consola del navegador y prueba las funciones en el entorno previsto por el proyecto.
